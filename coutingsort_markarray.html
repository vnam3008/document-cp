Tư Duy Lùa Bò Vào Chuồng

Hãy tưởng tượng bạn là chủ một nông trại có một đàn bò lộn xộn gồm 3 loại: Bò Sữa (Màu 0), Bò Vàng (Màu 1) và Bò Đen (Màu 2). Cuối ngày, bạn muốn đếm xem mỗi loại có bao nhiêu con.

🐢 Cách làm "Chậm"

Bạn chạy ra bãi cỏ, đếm từng con bò sữa. Xong xuôi, bạn lại phải chạy ra bãi cỏ một vòng nữa để tìm và đếm bò vàng.

Nhược điểm: Duyệt đàn bò nhiều lần. Máy tính sẽ bị chậm!

🚀 Cách làm "Nhanh"

Bạn xây sẵn 3 cái chuồng (đánh số 0, 1, 2). Bạn lùa cả đàn đi qua cổng, hễ gặp con bò màu gì thì đẩy luôn nó vào chuồng có số đó.

Ưu điểm: Chỉ duyệt 1 lần duy nhất. Muốn biết số lượng, ra nhìn chuồng là xong!

Từ Nông Trại đến Tin Học!

Trong lập trình, Đàn bò chính là Mảng dữ liệu ban đầu (Mảng A). Còn Các cái chuồng chính là Mảng Đếm (Mảng countArray).

// Tư duy cốt lõi của Đếm Phân Phối:

"Sử dụng GIÁ TRỊ của phần tử làm CHỈ SỐ (Index) cho mảng đếm"

Bò Màu 2 đi qua ➔ countArray[2]++

Mô Phỏng Trực Quan

Cách mảng đếm hoạt động thực tế qua ví dụ lùa đàn 6 con bò vào chuồng.

Bãi cỏ (Mảng A): [2, 0, 1, 2, 2, 0]
Chuồng bò (Mảng countArray):
0
Chuồng 0 (Sữa)
0
Chuồng 1 (Vàng)
0
Chuồng 2 (Đen)
Đang lùa bò...
counting_array.cpp 
int A[] = {2, 0, 1, 2, 2, 0}; // Đàn bò 6 con (0: Sữa, 1: Vàng, 2: Đen)
int n = 6;

// 1. Khai báo 3 cái chuồng và dọn sạch sẽ (gán bằng 0)
int countArray[3] = {0, 0, 0}; 

// 2. Lùa từng con qua cửa
for (int i = 0; i < n; i++) {
    int mauBo = A[i]; 
    // Đẩy bò vào chuồng tương ứng với màu của nó
    countArray[mauBo]++; 
}

// 3. Muốn biết số bò đen (Màu 2)? Ra nhìn chuồng số 2 thôi!
cout << "So bo den la: " << countArray[2]; // In ra 3

Đánh Dấu (Marking Array)

Là phiên bản "thu gọn" của đếm phân phối. Ta không quan tâm CÓ BAO NHIÊU con, ta chỉ quan tâm CÓ XUẤT HIỆN HAY KHÔNG?

🏫

Ví dụ: Điểm danh vắng mặt

Lớp có 1 triệu học sinh (mã số từ 1 đến 1000000). Hôm nay có 3 bạn đi muộn là [4, 1, 5]. Làm sao để thầy giám thị biết nhanh mã số 3 có đi muộn hay không?

Giải pháp O(1)

  • 1 Tạo mảng bool diMuon[1000001] = {false}
  • 2 Duyệt danh sách, đánh dấu diMuon[x] = true
  • 3 Tra cứu cực nhanh: if (diMuon[3]) ...

Tại sao dùng mảng Bool thay vì Int?

Kiểu bool (True/False) chỉ tốn 1 byte bộ nhớ. Trong khi kiểu int tốn 4 bytes. Nếu chỉ cần biết Có/Không, dùng mảng đánh dấu bool sẽ tiết kiệm RAM gấp 4 lần cho bài toán lớn!

Luyện Tập & Bẫy CP

Áp dụng tư duy vào giải bài tập. Hãy thử tự nghĩ thuật toán trước khi bấm vào xem code giải nhé!

Bài 1: Đếm số phần tử phân biệt

Dễ Mảng Đánh Dấu

Đề bài: Cho mảng A gồm N phần tử (N ≤ 105). Các giá trị 0 ≤ A[i] ≤ 106. Đếm xem có bao nhiêu con số khác nhau xuất hiện trong mảng?

Ví dụ: Mảng A = [2, 1, 2, 5, 1] ➔ Đáp án là 3 (gồm các số 1, 2, 5).

Xem thuật toán & Code giải C++ ▼ 
#include <iostream>
using namespace std;

// Khai báo biến toàn cục (Mảng boolean tự động được gán bằng false)
// Kích thước 1000005 để chứa vừa số lớn nhất có thể là 10^6
bool mark[1000005]; 

int main() {
    int n; 
    cin >> n;
    int count = 0; // Bộ đếm số lượng phần tử khác nhau
    
    for(int i = 0; i < n; i++) {
        int x; 
        cin >> x;
        // Nếu con số x này CHƯA TỪNG xuất hiện (mark[x] đang là false)
        if(mark[x] == false) {
            count++;            // 1. Ghi nhận thêm 1 số mới
            mark[x] = true;     // 2. Đánh dấu là x đã xuất hiện rồi nhé!
        }
        // (Nếu x đã xuất hiện rồi thì bỏ qua không đếm nữa)
    }
    
    cout << count;
    return 0;
}
Giải thích logic: Giống như thầy giáo điểm danh. Thầy cầm danh sách học sinh (mảng mark), ban đầu ai cũng vắng mặt (false). Khi đọc tên bạn x đi học, nếu thấy bạn này nãy giờ chưa điểm danh, thầy sẽ cộng 1 vào sĩ số và đánh dấu mark[x] = true. Nếu lát sau lại có người hô tên bạn x nữa, thầy nhìn sổ thấy true rồi nên lờ đi.

Bài 2: Tìm "Hoa Hậu" (Phần tử xuất hiện nhiều nhất)

Trung bình Mảng Đếm

Đề bài: Cho mảng A gồm N phần tử (N ≤ 105, 0 ≤ A[i] ≤ 105). Tìm con số xuất hiện nhiều lần nhất trong mảng. Nếu có nhiều con số có cùng số lần xuất hiện nhiều nhất, hãy in ra số nhỏ nhất.

Ví dụ: Mảng A = [4, 2, 4, 1, 2, 4] ➔ Đáp án là 4 (xuất hiện 3 lần).

Xem thuật toán & Code giải C++ ▼ 
#include <iostream>
using namespace std;

int cnt[100005]; // Mảng đếm (Chuồng bò)

int main() {
    int n; cin >> n;
    int max_val = 0; // Lưu con số lớn nhất trong mảng A để thu hẹp phạm vi tìm kiếm
    
    // Bước 1: Lùa bò vào chuồng
    for(int i = 0; i < n; i++) {
        int x; cin >> x;
        cnt[x]++; // Con số x xuất hiện ➔ Chuồng x tăng 1
        if(x > max_val) max_val = x; // Cập nhật con số lớn nhất
    }
    
    // Bước 2: Đi dạo một vòng các chuồng để tìm chuồng đông nhất
    int ans = -1;       // Lưu "tên" con số xuất hiện nhiều nhất
    int max_freq = 0;   // Lưu "số lần" xuất hiện của nó
    
    // Duyệt từ 0 đến max_val (Duyệt theo chiều tăng dần để lấy số nhỏ nhất nếu bằng nhau)
    for(int i = 0; i <= max_val; i++) {
        if(cnt[i] > max_freq) {
            max_freq = cnt[i]; // Phá kỷ lục số lần xuất hiện
            ans = i;           // Ghi nhận "tên" kẻ phá kỷ lục
        }
    }
    
    cout << ans;
    return 0;
}
Giải thích logic: Đầu tiên ta dùng Mảng đếm (như lùa bò vào chuồng) để thống kê sĩ số của từng con số. Bước 2, thay vì duyệt mảng ban đầu, ta đi bộ một vòng dọc theo các "chuồng" từ 0 đến max_val. Hễ thấy chuồng nào đông hơn kỷ lục cũ thì ta cập nhật kỷ lục mới. Vì ta duyệt từ nhỏ đến lớn (từ 0 trở lên), nên nếu có 2 chuồng đông BẰNG NHAU, chuồng số nhỏ hơn sẽ được giữ lại, giải quyết hoàn hảo yêu cầu đề bài!

Bài 3: Truy Tìm Số Bị Thiếu Nhỏ Nhất

Trung bình Mảng Đánh Dấu

Đề bài: Cho mảng A gồm N phần tử (N ≤ 105). Các giá trị trong mảng có thể là số âm hoặc dương vô cùng lớn. Hãy tìm số nguyên DƯƠNG (lớn hơn 0) nhỏ nhất không xuất hiện trong mảng.

Ví dụ: Mảng A = [3, 4, -1, 1] ➔ Đáp án là 2. (Vì 1 đã có, số nguyên dương nhỏ nhất tiếp theo bị khuyết là 2).

Xem thuật toán & Code giải C++ ▼ 
#include <iostream>
using namespace std;

// Chỉ cần đánh dấu đến 10^6 là an toàn cho bài toán CP thông thường
bool present[1000005]; 

int main() {
    int n; cin >> n;
    
    for(int i = 0; i < n; i++) {
        long long x; cin >> x;
        // Lọc cực gắt: Chỉ quan tâm các số DƯƠNG và không quá lớn (vừa mảng)
        // Bọn số âm (-1, -5) hay số 0 đều bị ngó lơ!
        if(x > 0 && x <= 1000000) {
            present[x] = true;
        }
    }
    
    // Bắt đầu dò từ số nguyên dương nhỏ nhất là 1
    for(int i = 1; i <= 1000005; i++) {
        if(present[i] == false) {
            cout << i; // In ra thủ phạm mất tích đầu tiên
            break;     // Bắt được rồi thì thoát vòng lặp ngay!
        }
    }
    
    return 0;
}
Giải thích logic: Đây là một bài kinh điển (First Missing Positive). Bẫy của bài này là có cả số âm. Nhưng tư duy cực kỳ đơn giản: Vì ta chỉ tìm số nguyên dương, ta ném hết bọn số âm đi không thèm quan tâm. Tạo một mảng đánh dấu present. Ai lớn hơn 0 thì đánh dấu true. Cuối cùng, dùng 1 vòng lặp chạy bắt đầu từ 1, 2, 3... hễ ô nào bị false (chưa ai đánh dấu) thì đó chính là số dương nhỏ nhất bị thiếu!

☠️ Điểm Chết Của Kỹ Thuật Này

Bạn TUYỆT ĐỐI KHÔNG được dùng mảng đếm/đánh dấu trong 2 trường hợp sau:

1. Giá trị mảng bị ÂM

Trong C/C++, chỉ số mảng (Index) không thể là số âm. Nếu A[i] = -5, lệnh countArray[-5]++ sẽ làm chương trình Crash ngay lập tức (Segmentation Fault).

2. Giá trị quá LỚN

Nếu A[i] = 109, bạn phải khai báo mảng int countArray[1000000000]. Cấp phát mảng quá lớn sẽ gây tràn RAM (Memory Limit Exceeded). Giới hạn an toàn tối đa thường là mảng ≈ 107 phần tử.

Giải pháp thay thế: Chuyển sang dùng cấu trúc dữ liệu std::map hoặc Sắp xếp (Sorting).
