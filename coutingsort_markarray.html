Khi đối mặt với bài toán cần thống kê hàng triệu phần tử trong Lập trình thi đấu (CP), việc dùng 2 vòng lặp lồng nhau có độ phức tạp O(N2) sẽ khiến bạn lập tức nhận kết quả Time Limit Exceeded (TLE). Kỹ thuật Phân phối ra đời để giải quyết việc này trong thời gian chớp mắt O(N).

counting_array.cpp 
int A[] = {2, 0, 1, 2, 2, 0}; // Mảng A lưu đàn bò 6 con
int countArray[100005] = {0}; // Khởi tạo các chuồng trống rỗng

// 1 vòng lặp duy nhất để lùa bò vào chuồng
for (int i = 0; i < 6; i++) {
    int loai_bo = A[i]; 
    countArray[loai_bo]++; // Bò loại nào thì tăng biến đếm của chuồng đó lên 1
}

cout << "So luong bo den (Loai 2) la: " << countArray[2]; // Output: 3

Thao Trường Luyện Tập

Lý thuyết là không đủ, hãy xem cách kỹ thuật này giải quyết gọn gàng các bài toán CP kinh điển.

Bài Dễ

1. Số xuất hiện nhiều nhất (Tần số max)

Cho mảng A gồm N phần tử (N ≤ 105, 0 ≤ A[i] ≤ 105). Hãy in ra số xuất hiện nhiều nhất trong mảng.

▶ Xem Code C++ & Giải thích 
int count[100005] = {0};
int max_freq = 0, ans = -1;

// BƯỚC 1: Duyệt qua mảng A để đếm tần số (Lùa bò vào chuồng)
for(int i = 0; i < N; i++) {
    count[A[i]]++; 
}

// BƯỚC 2: Duyệt qua CÁC CHUỒNG BÒ để tìm chuồng đông nhất
for(int i = 0; i <= 100000; i++) {
    if(count[i] > max_freq) {
        max_freq = count[i]; // Cập nhật kỷ lục số lượng
        ans = i;             // Lưu lại TÊN CHUỒNG (Giá trị phần tử)
    }
}
cout << ans;
Trung bình

2. Lọc phần tử trùng lặp (Unique Array)

Cho mảng A. Hãy in ra các số trong mảng theo đúng thứ tự ban đầu, nhưng mỗi số chỉ được in ra đúng 1 lần (loại bỏ các số lặp lại).

▶ Xem Gợi ý dùng Mảng Đánh Dấu 
// Sử dụng mảng bool để tiết kiệm dung lượng bộ nhớ nhất
bool mark[100005] = {false}; 

for(int i = 0; i < N; i++) {
    // Nếu số này chưa từng xuất hiện (chưa đánh dấu)
    if(mark[A[i]] == false) { 
        cout << A[i] << " ";  // 1. In nó ra
        mark[A[i]] = true;    // 2. Đánh dấu vào sổ là ĐÃ GẶP RỒI!
    }
    // Nếu mark == true -> Không thỏa mãn IF -> Máy tính tự động bỏ qua số này
}
Bẫy Chí Mạng

3. Sát thủ mang tên "Chỉ số Âm"

Nguyên tắc của mảng trong C++ là không có chỉ số âm (Bạn không thể gọi count[-5]). Vậy nếu đề bài cho các phần tử có thể mang giá trị âm (Ví dụ: -1000 ≤ A[i] ≤ 1000), bạn phải làm sao để đánh dấu?

💡 Cách giải quyết: Tịnh tiến mảng (Offset Technique)

Hãy cộng thêm một lượng bù (Offset) bằng đúng giá trị âm bé nhất để "đẩy" mọi giá trị thành số dương (từ 0 trở lên).

// Thay vì viết: count[A[i]]++ (sẽ lỗi nếu A[i] = -1000)
count[ A[i] + 1000 ]++;
